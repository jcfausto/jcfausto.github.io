## Never Stop Learning

I’m curious by nature, and as a side effect of this characteristic, I’m always learning something new!

That time couldn’t be different.

Today I will share with you my first Mobile UI project.

This project consists on a recreation ( Learning by doing! ) in Adobe Photoshop of the [Udemy](https://www.udemy.com) mobile app UI and also a clickable prototype using [inVision](http://invisionapp.com).

Well, first see below the final result and after, some explanations about the building process and my course experience until now.

Enjoy!

This is the first outcome of my ongoing [***iOS 8 Mobile App Design: UI & UX Design***](https://www.udemy.com/design-ios-8-apps-from-scratch) course at [Udemy](http://udemy.com).

( you can see it here too:[http://invis.io/ZS2CTK9Q5](http://invis.io/ZS2CTK9Q5))

## My Course Experience Until Now

Well, I’m really having fun with this course.

First thing to notice is that the course “[iOS 8 Mobile App Design: UI & UX Design](https://www.udemy.com/design-ios-8-apps-from-scratch)” is a well built course.

It is very didactic and has all the necessary steps to start with no knowledge in Mobile Design and finish with a good foundations about it.

I’m currently in the middle of the course and at this point I’ve finished the first project and reached the first outcome, that is to recreate the Udemy mobile app user interface and put everything together on a clickable prototype.

For the design recreation (yes, everything was recreated by me) I’m using Photoshop CC.

For the prototyping, I’m using [inVision](http://invisionapp.com). By the way, this tool is really amazing. really.
